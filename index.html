Kotnot-C - Полная документация

Версия: 8.0 Ultimate | Компилятор: kc | Лицензия: MIT

Введение

Kotnot-C - современный язык программирования с C-подобным синтаксисом, созданный для системного и прикладного программирования.

Синтаксис

// Пример программы на Kotnot-C
import std.io;

func main() -> int {
    println("Hello, Kotnot-C!");
    return 0;
}

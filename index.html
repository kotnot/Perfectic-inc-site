Gitrex Message - Документация

Версия: 1.4

Платформы: Windows, Linux

Настройка:

  1. Создайте аккаунт или войдите
  2. Настройте профиль (аватар, статус)
  3. Добавьте контакты по username
  4. Начните общение в личных или групповых чатах

Безопасность:

Все сообщения шифруются с помощью алгоритма AES-256. Ключи шифрования хранятся только на устройствах пользователей.

GitrexOS - Документация

Версии: Original (полная), Lite (облегченная)

Архитектура: x86_64

Установка:

  1. Скачайте образ (IMG или BIN)
  2. Запишите на USB-накопитель с помощью Rufus или аналогичной программы
  3. Загрузитесь с USB
  4. Следуйте инструкциям установщика

Kotnot-C - Документация

Версия языка: 1.1

Компилятор: kc (Kotnot-C Compiler)

Пример программы:

// Пример программы на Kotnot-C
import std.io;

func main() -> int {
    println("Hello, Kotnot-C!");
    
    let x: int = 10;
    let y = 20; // автоматическое определение типа
    
    let sum = x + y;
    println("Sum: {}", sum);
    
    return 0;
}
